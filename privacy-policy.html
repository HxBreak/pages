Privacy Policy

Effective Date: August 11, 2026 | Last Updated: September 8, 2026

🛡️ Summary: Absolute Privacy & Zero Data Collection

DevCheck does not collect, transmit, or share any personal or device data.

All hardware, system, and network diagnostic information is accessed and processed strictly on your local device. No data is ever transmitted to our servers, third parties, or outside your device.

🔒 100% On-Device Processing
🚫 Zero Data Collection / Sharing
📡 No Internet Access Permission
⚙️ Revocable In-App Consent

1. Information We Access On-Device

To display device specifications and diagnostics, DevCheck accesses the following categories of information locally:

Category Examples Type / Handling
Device Manufacturer, model, board, hardware specs Non-sensitive / Local only
Android OS OS version, API level, build number, security patch Non-sensitive / Local only
CPU & SoC SoC model, architecture (ABIs), core count, frequencies Non-sensitive / Local only
Memory (RAM) Total RAM, available memory, swap usage Non-sensitive / Local only
Storage Internal storage capacity and free space Non-sensitive / Local only
Battery Health, battery level, temperature, voltage, technology Non-sensitive / Local only

Network Network type (Wi-Fi / Cellular), local IP address Local diagnostic only
Wi-Fi Details Connected SSID, BSSID, link speed, frequency Requires Explicit Permission

2. Data Collection, Transmission, and Sharing

  • No Collection: Under Google Play developer policies, "collection" means transmitting data off the device. Because DevCheck processes all data locally and sends nothing off the device, no data is collected.
  • No Third-Party SDKs: DevCheck includes no analytics SDKs (e.g. Firebase, Google Analytics), no advertising networks, and no telemetry services.
  • No Internet Permission: The app does not declare or request the android.permission.INTERNET permission in its manifest, guaranteeing that network transmissions cannot occur.
  • No Data Sharing: We do not sell, rent, or share any data with any third party.

3. Permissions and User Consent

DevCheck is designed with minimum privilege:

  • Install-time permissions: Only ACCESS_NETWORK_STATE is declared, which allows checking the current network connection type locally.
  • Runtime permissions (Location): On Android, obtaining detailed Wi-Fi identifiers (SSID/BSSID) requires Location permission (ACCESS_FINE_LOCATION). DevCheck only requests this permission if you navigate to the Wi-Fi details screen and tap to view Wi-Fi parameters.
  • Revoking Access: You can grant or revoke this access at any time via Settings → Data Access within the app, or through Android System Settings. Once revoked, the information is immediately cleared from the display.

4. Data Retention & Deletion

  • We operate no backend servers or databases; therefore, no user data exists remotely to be retained or deleted.
  • The only data persisted locally on your device is your consent state (which categories you permitted).
  • Uninstalling DevCheck permanently erases all locally saved preferences.

5. Google Play Data Safety Compliance

In the Google Play Console "Data Safety" form, DevCheck declares:

  • Does your app collect or share any user data? → No
  • Data encryption in transit: N/A (no data transmitted)
  • Data deletion requests: N/A (no user data stored remotely)

6. Children's Privacy

DevCheck is not directed towards children under the age of 13 (or under 16 in certain jurisdictions), and does not collect personal information from anyone.

隐私权政策

DevCheck（设备检测）不会收集、传输或共享任何用户的个人或设备数据。

应用内显示的所有硬件规格、系统运行状态和网络诊断信息均完全在您的本地设备上读取与处理。任何数据都不会发送至我们的服务器、任何第三方或离开您的设备。

🔒 100% 设备本地处理
🚫 零数据收集与共享
📡 无联网权限声明

1. 我们在本地读取的信息

2. 数据收集、传输与分享政策

  • 无数据收集：根据 Google Play 开发者政策定义，“数据收集”指将数据传输到用户设备之外。DevCheck 所有数据均在设备本地处理，绝不向外部传输，因此不属于数据收集。
  • 无第三方 SDK：本应用未集成任何第三方统计分析 SDK（如 Firebase、Google Analytics）、广告 SDK、崩溃报告或用户画像组件。
  • 无 INTERNET 联网权限：应用清单未声明 android.permission.INTERNET 权限，从操作系统层面保证无法发起网络传输。
  • 无数据共享：我们绝不会向任何第三方出售、出借或分享任何信息。

3. 权限使用与用户知情同意

DevCheck 遵循最小权限原则：

  • 安装时权限：仅声明了普通的 ACCESS_NETWORK_STATE（仅用于本地识别网络连接类型）。
  • 运行时权限（位置信息）：根据 Android 规范，读取 Wi-Fi 的 SSID / BSSID 需要位置权限（ACCESS_FINE_LOCATION）。应用仅在用户进入 Wi-Fi 详情页面并明确请求查看时，才会通过前置弹窗（Prominent Disclosure）说明原因并申请该权限。
  • 随时撤销：您可以在应用内的“设置 → 数据访问”或系统设置中随时撤销此权限。撤销后，应用将立即停止读取并清除界面上的对应信息。

4. 数据存储与删除

  • 我们未架设任何云端服务器或数据库，因此不存在任何远程存储的用户数据。
  • 在您的设备本地，应用仅持久化保存您的授权选择（如是否允许读取 Wi-Fi）。
  • 卸载应用即可彻底清除应用在您设备上存储的所有本地配置。

5. Google Play 数据安全表单一致性声明

在 Google Play 管理中心的“数据安全”部分，DevCheck 声明如下：

  • 应用是否收集或分享任何用户数据？ → 否
  • 传输过程中数据是否加密： 不适用（无网络传输）
  • 数据删除机制： 不适用（未在远程存储任何数据）

6. 儿童隐私保护

本应用不面向 13 岁（或您所在司法管辖区规定的对应年龄）以下的儿童，且不会收集任何人的个人数据。
